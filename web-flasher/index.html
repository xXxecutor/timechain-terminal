₿ Timechain Terminal

Firmware für das Good Display GDP075FW1 (7,5" E-Paper, 4 Farben) – direkt aus dem Browser installieren.

1. Gerät anschließen

Das Schild per USB-Kabel mit dem Computer verbinden. Es meldet sich als „USB-SERIAL CH340“. Fehlt unter Windows der Treiber, den CH340-Treiber des Herstellers WCH installieren.

2. Installieren

Dein Browser kann keine USB-Geräte ansprechen. Bitte Chrome oder Edge am Computer verwenden. Die Seite muss über HTTPS geöffnet werden.

Bei der ersten Installation „Gerät löschen“ bestätigen. Das Schreiben dauert etwa 2 Minuten.

3. WLAN einrichten

  1. Das Display zeigt „WLAN einrichten“.
  2. Mit dem Handy das WLAN Timechain-Terminal wählen, die Einrichtungsseite öffnet sich.
  3. „Configure WiFi“ – das eigene 2,4-GHz-WLAN wählen und das Passwort eingeben. Optional einen eigenen mempool-Server eintragen.

Danach erreichst du das Gerät im Heimnetz unter http://timechain-terminal.local (Einstellungen, Layout, Firmware-Updates ohne Kabel).

Neue Versionen gibt es unter Releases als timechain-terminal-….bin für das Update über die Geräte-Webseite. Quellcode und Anleitung: github.com/xXxecutor/timechain-terminal.
